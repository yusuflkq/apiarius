# Security

Installing Apiarius should leave you exactly as safe as using Claude Code without it. If you find a way for a web page, another user or process on the machine, a repository or an agent to read what the deck holds, or to act through it in a way Claude Code alone wouldn't allow, please report it.

## Report a vulnerability

Report it privately, not in a public issue. On the repository's [Security tab](https://github.com/yusuflkq/apiarius/security), choose Report a vulnerability. Only you and the maintainer see the report until the maintainer publishes an advisory.

Say what you found, how to reproduce it, your Claude Code version and your OS, and where it happened (the terminal, the Desktop app's side pane or the web page).
